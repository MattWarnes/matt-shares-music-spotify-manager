Privacy Policy

Last updated: 21 November 2026

Spotify Manager is a personal tool operated by Matt Shares Music. It is used only with the operator's own accounts.

What data it uses

  • Public information about my own Spotify playlists (names, tracks, artists, cover art).
  • Access tokens for my own social media accounts (such as TikTok, Instagram and YouTube), used only to publish posts and read my own follower counts.

What it does not do

  • It does not collect, store or process data about other people.
  • It does not sell, share or transfer any data to third parties.
  • It does not use data for advertising or profiling.

Storage

Tokens and logs are stored only on my own computer and are never published.

Deleting data

Access can be revoked at any time from each platform's app settings, after which the stored tokens stop working and are deleted.
